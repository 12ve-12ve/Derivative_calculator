\doxysubsection{Detailed Description}

\hypertarget{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md10}{}\doxysubsection{\texorpdfstring{Description}{Description}}\label{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md10}
The Derivative Calculator is a desktop application developed in C++ that allows users to parse mathematical equations, calculate their derivatives, and visualize both functions simultaneously in real-\/time. The project utilizes the Dear Im\+Gui framework for the graphical user interface and the Im\+Plot library for rendering mathematical graphs. Under the hood, it implements a custom mathematical engine based on Reverse Polish Notation (RPN) and an Abstract Syntax Tree (AST) to process inputs, apply symbolic differentiation rules, and algebraically simplify the resulting expressions.\hypertarget{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md11}{}\doxysubsection{\texorpdfstring{Installation}{Installation}}\label{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md11}
To compile and run this project, you need a standard C++ development environment.\hypertarget{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md12}{}\doxysubsubsection{\texorpdfstring{Prerequisites}{Prerequisites}}\label{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md12}

\begin{DoxyItemize}
\item C++17 Standard or higher.
\item IDE:\+ Visual Studio 2022 (recommended for Windows users) or any compatible C++ compiler.
\item Dependencies:\+ The project requires the {\ttfamily Dear Im\+Gui} and {\ttfamily Im\+Plot} libraries. (Note:\+ Ensure that the include directories and linkers for these libraries are properly configured in your project properties if they are not already bundled).
\end{DoxyItemize}\hypertarget{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md13}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md13}
This application is highly useful for students, educators, and engineers who need to quickly visualize mathematical functions and analyze their rate of change (derivatives).

To use the calculator, simply interact with the on-\/screen keyboard or use your physical keyboard to type a valid mathematical function in terms of the independent variable {\ttfamily x}. The application will instantly parse the formula, generate the derivative, and plot both lines. You can freely pan the camera by clicking and dragging the graph, or zoom in and out using the mouse wheel. An integrated "{}\+Help"{} menu is available within the application.\hypertarget{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md14}{}\doxysubsection{\texorpdfstring{Examples}{Examples}}\label{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md14}
A standard use case involves analyzing complex trigonometric and polynomial bounds. For instance, inputting the formula {\ttfamily sin(pow(x, 2)) + 2 \texorpdfstring{$\ast$}{*} x} will automatically compute the exact derivative {\ttfamily cos(pow(x, 2)) \texorpdfstring{$\ast$}{*} 2 \texorpdfstring{$\ast$}{*} x + 2} (simplified through the AST engine) and display their respective intersections on the graph.

\hypertarget{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md15}{}\doxysubsection{\texorpdfstring{Features}{Features}}\label{dir_3e6c5c9ebbda3756758fb1f5b985ab1a_autotoc_md15}

\begin{DoxyItemize}
\item {\bfseries{Custom AST Parsing Engine:\+}} Converts standard infix mathematical notation into Reverse Polish Notation and builds a traversable syntax tree.
\item {\bfseries{Symbolic Differentiation:\+}} Dynamically applies the chain rule, product rule, and quotient rule to calculate exact derivatives instead of relying on numerical approximations.
\item {\bfseries{Algebraic Simplification:\+}} Automatically reduces mathematical clutter (e.\+g., multiplying by zero or one) for cleaner derivative output.
\item {\bfseries{Real-\/\+Time Graphing:\+}} Rendering of multiple functions using Im\+Plot.
\item {\bfseries{Comprehensive Math Support:\+}} Supports basic arithmetic, trigonometry, cyclometric functions, hyperbolic functions, logarithms, powers and natural constants (π, e).
\item {\bfseries{Robust Error Handling:\+}} Instantly detects parsing errors, missing brackets, or invalid syntax and alerts the user through the UI without crashing the application. 
\end{DoxyItemize}
